# Beim Wechsel auf Fragen soll der Fragen-Filter geschlossen sein

## Status: Open

## Beschreibung

Wenn der User ins Lernen-Tab (Fragen-Ansicht) wechselt, soll der Fragen-Filter standardmäßig geschlossen/eingeklappt sein.

## Aufgaben

1. Herausfinden, wo der Tab-Wechsel im Frontend gehandhabt wird
2. Filter-State beim Wechsel auf "closed" setzen
3. Testen, dass der Filter beim Tab-Wechsel geschlossen ist
